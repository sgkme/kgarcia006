# Snack Stack catalog download

Download `Snack-Stack-Catalog.zip`, extract it, and open the new `Snack-Stack-Catalog.html` in Chrome or Edge. Click **Watch the menu run**.

The single HTML file works offline and contains all 105 menu items, ingredient inspection, artwork animations, the full animated menu run, and the flatter pizza perspective. The preview starts with Pepperoni Pizza.

This version fixes Chrome/Edge playback freezing when an ingredient lands and corrects pouring/fill clip transforms. Validation exercised real animation-frame playback, pause/resume, and 6,300 intermediate frames across all 105 menu items and the four original kit recipes, with no browser errors.

The additional menu recipes are catalog-derived previews. The four original kit recipes remain in their own collection.
