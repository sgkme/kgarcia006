# Snack Stack catalog download

Download `Snack-Stack-Catalog.zip`, extract it, and open the new `Snack-Stack-Catalog.html` in Chrome or Edge. Click **Watch the menu run**.

The single HTML file works offline and contains all 125 menu items, ingredient inspection and SVG downloads, artwork animations, the full animated menu run, and the flatter pizza perspective. The preview starts with the 20 new ice cream sandwiches, then continues through the previous menu items.

The two new ice cream sandwich collections include all 20 finished items from Sets 1 and 2. Each lower cookie, filling, upper cookie, and applied coating is a separate catch. Scoops settle into the filling before the upper cookie arrives. Ingredients has a separate library with category controls for 35 reusable cookie, ice cream, and topping assets.

`Ice-Cream-Sandwich-SVGs.zip` contains the 20 finished SVGs, 35 ingredient SVGs, two label-free sheets, and recipe JSON. The same pack is included inside the catalog ZIP. `Ice-Cream-Sandwich-Preview.png` shows all 20 additions; `ICE-CREAM-SANDWICHES.md` records the recipe and reference choices.

This recipe-audit update separates upper/lower layers into individual catches, fills drinks before adding toppings, and assembles flat tortillas before wrapping. Breakfast burritos have six ingredient steps. Waffles share the pancake perspective and syrup process; sandwich bread has rounded crust and porous crumb. Bowls and fries are fuller, enchilada cheese follows each roll, and cut faces remain attached to their food. Whole containers stay intact.

Order changes and tab navigation continue requested playback; explicit Pause stays paused. Validation served all 125 menu items, completed 375 engine runs across three difficulties, and rendered 9,360 intermediate frames across the 125 menu items and four kit recipes with no browser errors. The new ingredient library, independent cookie exports, mobile layout, and offline downloads were checked. The previous 105 SVG artwork files are unchanged.

The ZIP includes `RECIPE-AUDIT.md` with the findings and corrections. It is also available beside this README.
