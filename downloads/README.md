# Snack Stack catalog download

Download `Snack-Stack-Catalog.zip`, extract it, and open `Snack-Stack-Catalog.html` in a browser.

The single HTML file works offline and contains all 105 menu items, ingredient inspection, the full animated menu run, and the flatter pizza perspective. The preview starts with Pepperoni Pizza.

The additional menu recipes are catalog-derived previews. The four original kit recipes remain in their own collection.
